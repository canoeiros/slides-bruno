① Amostragem (Sampling) → ② Quantização (Levels) → ③ Codificação Binária
Saída Binária (código atual)
ADC: O sinal contínuo é amostrado a cada período Ts, e cada amostra é quantizada para o nível discreto mais próximo (2N níveis). O resultado é um código binário de N bits. Menos bits = maior erro de quantização.
